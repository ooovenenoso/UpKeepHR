# Seguridad y privacidad

No publiques credenciales, expedientes del personal, documentos originales, enlaces de activación o respaldos en GitHub.

Para reportar una vulnerabilidad, utiliza **Security → Report a vulnerability** en este repositorio. Incluye pasos reproducibles con datos ficticios, impacto y versiones afectadas. No pruebes sobre instalaciones de terceros ni adjuntes datos reales.

El proyecto se distribuye sin una certificación independiente de seguridad. Antes de producción, revisa autorización, configuración de proveedores, secretos, restauración de respaldos y políticas de retención. La publicación del código no implica una garantía de cumplimiento normativo.
