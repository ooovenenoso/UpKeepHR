# Marca UpKeepHR

La interfaz, descargas, Excel y PDF utilizan exclusivamente UpKeepHR. El símbolo propio combina una ficha documental y una verificación sobre fondo azul, con acentos turquesa y amarillo.

- public/brand/upkeephr-logo.svg: fuente vectorial editable.
- public/brand/upkeephr-logo.png: rasterización del mismo símbolo para Next.js, Excel y PDF.
- public/brand/workspace.svg: ilustración vectorial de documentación organizada para acceso, dashboard y portal del empleado.

Los gráficos fueron creados en código para esta plataforma. No incluyen fotografías de personas ni marcas de otra organización. Los documentos originales cargados por empleados mantienen sus bytes originales; solo los reportes y comprobantes generados incluyen la marca del sistema.
